# ADR-001 — BCOS CLI 구현 언어

- **상태:** Accepted
- **날짜:** 2026-08-03
- **결정자:** Claude (Architect) / Human 승인 대기
- **관련:** [ADR-002](ADR-002-storage.md), [v0.1-scope.md](../v0.1-scope.md)

---

## 맥락

Notion 설계 문서의 Immediate Next Steps에 "CLI 구현 언어 선정"이 미결로 남아 있었다.

제약 조건:

1. **Windows가 1차 실행 환경이다.** (개발자 환경: Windows 10, PowerShell 5.1, Git Bash 병행)
2. **배포 마찰이 낮아야 한다.** 개인 도구에서 오픈소스로 확장할 계획이다.
3. **파일 I/O와 텍스트 파싱이 전부다.** 계산 부하는 사실상 없다.
4. **BCOS는 LLM을 호출하지 않는다.** 무거운 SDK 의존이 필요 없다.
5. Codex CLI가 이 저장소의 구현 담당이다. Codex가 익숙한 생태계일수록 좋다.

## 검토한 선택지

| 언어 | 장점 | 단점 |
|---|---|---|
| **Node.js + TypeScript** | `npx bcos`로 설치 없이 실행, 크로스플랫폼 경로 처리 성숙, Codex CLI와 동일 런타임(이미 설치됨), 타입으로 데이터 모델 강제 | 런타임 의존, 시작 시간 ~50ms |
| Go | 단일 바이너리, 시작 즉시, 배포 간단 | 개발자 환경에 미설치, 크로스 컴파일 파이프라인 필요, 반복 속도 느림 |
| Python | 텍스트 처리 간편 | Windows에서 버전·PATH 지옥, 배포가 가장 어려움 |
| Rust | 성능·안정성 | v0.1 규모에 과잉. 반복 속도 최악 |

## 결정

**Node.js 22+ / TypeScript**로 구현한다.

- 패키지 매니저: npm
- 빌드: `tsc` (번들러 없음 — v0.1 규모에 불필요)
- 실행: `npx bcos` 또는 `npm link` 후 `bcos`
- 테스트: `node:test` (내장) — 외부 테스트 러너 의존 없음
- 런타임 의존성: **0개를 목표로 한다.** frontmatter 파싱, 인자 파싱 모두 직접 구현.
  (v0.1의 파싱 요구는 100줄 미만이다. 의존성을 넣는 쪽이 더 비싸다.)

## 근거

- **제약 3·4가 성능 요구를 없앤다.** Go/Rust의 주 장점이 v0.1에서 무의미하다.
- **제약 1·2에서 Node가 이긴다.** `npx`는 Windows에서 가장 마찰이 적은 배포 경로다.
- **제약 5** — Codex CLI가 이미 Node로 설치되어 있다(`AppData/Roaming/npm/codex`).
  런타임이 이미 검증된 상태다.
- 의존성 0 정책은 "Small Context by Default" 원칙과 같은 방향이다.
  `node_modules`가 없으면 Codex가 읽어야 할 것도 줄어든다.

## Windows 관련 필수 규칙

이 결정을 채택하면 구현 시 다음을 반드시 지킨다.

- 경로는 항상 `path.join` / `path.resolve`. 하드코딩된 `/` 또는 `\` 금지
- 파일 쓰기는 **temp write → `fs.renameSync`** (원자적)
- 파일 읽기·쓰기 인코딩은 항상 `utf8` 명시
- 개행은 LF로 통일. `.gitattributes`에 `* text=auto eol=lf`
- 문서의 예시 명령에 `&&` 체이닝을 쓰지 않는다 (PowerShell 5.1 파서 오류)
- Task ID·파일명에 `:` `?` `*` `<` `>` `|` 금지

## 결과

**긍정**
- 반복 속도가 빠르다. v0.1은 며칠 단위로 갈아엎을 수 있어야 한다.
- 배포 경로가 하나(`npx`)로 명확하다.
- 타입으로 Task/State/Event 스키마를 컴파일 타임에 강제할 수 있다.

**부정 (수용함)**
- Node 런타임이 필요하다. → 대상 사용자가 이미 AI CLI를 쓰는 개발자이므로 사실상 항상 있다.
- 시작 시간 ~50ms. → 대화형 CLI에서 체감 불가.

**되돌리는 조건**
- 시작 시간이 실사용에 걸릴 정도가 되면 Go 단일 바이너리로 재작성한다.
  데이터 모델이 순수 텍스트 파일이므로 **재작성 비용은 CLI 계층에만 국한된다.**
  이것이 ADR-002를 먼저 확정한 이유다.
