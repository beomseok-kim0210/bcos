# Amendment A001 — T-013 run artifact identity field naming

## Superseded

- AC 59
- AC 62
- AC 63

Scope §8의 run artifact 필드 표도 같은 정정을 따른다.

## Original

```
59. run artifact가 `worker_runtime`과 `reviewer_runtime`을 **별도 필드로** 담는다.
62. worker stage 이후 run artifact에 `worker_runtime`이 기록된다.
63. review stage 이후 run artifact에 `reviewer_runtime`이 기록된다.
```

Scope §8:

```
| `worker_runtime` · `worker_version`     | worker stage 종료 후 |
| `reviewer_runtime` · `reviewer_version` | review stage 종료 후 |
```

## Corrected

```
59. run artifact가 `worker_name`과 `reviewer_name`을 **별도 필드로** 담는다.
62. worker stage 이후 run artifact에 `worker_name`이 기록된다.
63. review stage 이후 run artifact에 `reviewer_name`이 기록된다.
```

Scope §8:

```
| `worker_name` · `worker_version`     | worker stage 종료 후 |
| `reviewer_name` · `reviewer_version` | review stage 종료 후 |
```

## Reason

`docs/benchmarks/TELEMETRY.md`는 **T-009부터** 두 키를 서로 다른 뜻으로 정의해 왔다.

```
| `worker_name`    | 문자열 | `--worker` 값                          | now   |
| `worker_runtime` | 문자열 | worker 실행 형태. 예: `node <codex.js>` | T-009 |
```

`reviewer_name` · `reviewer_runtime`도 같은 구조다 (같은 문서 276–277행).

즉 **`worker_runtime`은 "어떻게 띄웠는가"(`node` · `native`)라는 뜻을 이미 갖고
있었고, "어느 실행기인가"(`codex` · `claude`)에 해당하는 규범 키는 `worker_name`**이다.

T-013 Task는 run artifact 필드 이름을 `worker_runtime` / `reviewer_runtime`으로
지정했으나, 그 자리에 담기는 값은 `codex` / `claude` — 즉 **`worker_name`의 값**이다.
같은 키 이름이 stdout telemetry와 run artifact에서 서로 다른 의미를 갖게 되는
data contract 결함이며, T-016 Benchmark Harness가 artifact를 읽을 때
예외 없이 조용히 어긋난다.

**이 결함의 출처는 구현이 아니라 Task 설계다.** worker는 Task 문언을 정확히
구현했다. Attempt 1 Review가 이를 발견하고 `worker_name` / `reviewer_name`으로의
변경을 요구했으며, Attempt 2 구현이 그것을 따랐다.

## Scope Change 여부

**correction이다. scope change가 아니다.**

- Task의 Objective — "실행기 경계를 만든다" — 그대로다.
- Scope §8의 목적 — "artifact만으로 어느 실행기를 썼는지 알 수 있다" — 그대로다.
- 기록되는 **값**(`codex` · `claude` · 버전)은 바뀌지 않는다. **키 이름만** 바뀐다.
- 요구가 늘지도 줄지도 않는다. AC 개수는 94개 그대로다.
- 기준을 낮추지 않는다 — 오히려 기존 규범과의 정합을 회복한다.

T-900 Task Contract §5의 판별 기준 — *"정정 후 Task의 목적이 그대로인가"* — 를
충족한다.
